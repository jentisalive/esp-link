# ESP Link — Wi-Fi ONLY (1.3.0)

Локальный пульт для **uPesy ESP32 Wroom DevKit**: Android 8+, iPhone/iPad iOS 16+ и прошивка платы. **Bluetooth полностью удалён из приложений и отключён в новой прошивке.** Плата не запускает Bluetooth-сервисы, поиск или advertising; приложения не запрашивают Bluetooth и геолокацию.

## Обновление с 1.0 / 1.1

**Нужно заново прошить ESP32 и обновить приложение.** Только установка нового APK не выключит Bluetooth в старой прошивке платы. При обычной загрузке с прежней разметкой NVS токен управления сохраняется, а отдельный пароль Wi-Fi создаётся автоматически. Полное стирание flash для обновления не требуется.

## Начало работы на Windows

1. Подключите плату USB-кабелем с передачей данных. Закройте Serial Monitor Arduino IDE.
2. Запустите **flash_esp32.bat** в подготовленной папке проекта. Это заменит текущую программу платы.
3. Запустите **get_token.bat**, нажмите **EN** на плате (это RESET). Монитор 115200 покажет:

   ```text
   Device / Wi-Fi SSID: ESP32-Link-XXXX
   Device token: <латинские буквы или цифры>
   Wi-Fi password: <отдельный пароль сети>
   HTTP address: http://192.168.4.1
   ```

4. В настройках телефона подключитесь к `ESP32-Link-XXXX`, используя **Wi-Fi password**. Останьтесь в сети без интернета.
5. Откройте ESP Link, введите адрес `192.168.4.1` и **Device token**, подключитесь. На iPhone разрешите локальную сеть.
6. Нажмите «Мигнуть 3 раза» или отправьте `1`. Также: `on`, `off`, `status`, `ping`.

Токен и пароль — **не одно и то же**. Не публикуйте вывод USB Serial.

### Поменять пароль Wi-Fi без перепрошивки

Запустите **change_wifi_password.bat** рядом с остальными файлами проекта. Закройте другие USB-мониторы. Введите новый пароль дважды; ввод скрыт. При нескольких портах выберите свою плату.

```cmd
change_wifi_password.bat COM5
```

Пароль: 8–63 печатных ASCII-символа без пробелов; рекомендуется случайный пароль не короче 16 символов. Он сохраняется в NVS и действует после отключения питания. Wi-Fi перезапустится, телефон отключится: забудьте старую сеть и подключитесь с новым паролем. **Device token не меняется.** Смена доступна только через физический USB, сетевого API для неё нет.

### Заменить Device token

Обновите прошивку через `flash_esp32.bat`, закройте Serial Monitor и запустите `change_device_token.bat` (при необходимости `change_device_token.bat COM5`). Новый токен сохраняется в NVS; старый сразу перестаёт работать, пароль Wi-Fi не меняется. Чтобы узнать сохранённый токен, запустите `get_token.bat` и нажмите EN.
В батнике пункт `1` генерирует токен. Пункт `2` позволяет ввести свой токен дважды. Для ручного ввода нужны прошивка 1.2.4 или новее и обновлённое приложение: опубликованные приложения 1.2.0 принимают только 12 hex-символов. Допустимы 8–64 символа: латинские буквы `A–Z` и цифры `0–9`, без пробелов внутри. Регистр не важен. Символы видны при вводе: не показывайте окно посторонним. Не используйте пароль Wi-Fi, старый токен или легко угадываемые комбинации.

Батники используют `.venv` с PlatformIO из папки проекта. На другом компьютере сначала подготовьте окружение:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install platformio==6.1.18
```

Порт при необходимости: `flash_esp32.bat COM5` / `get_token.bat COM5`. Если загрузка зависла на Connecting, удерживайте BOOT до начала записи. Кнопка EN перезапускает плату, BOOT для просмотра токена не нужен.

## Приложения и сборки

- Android: готовый подписанный APK из Releases. Установите с разрешением установки из выбранного источника; самостоятельная подпись не нужна. [ANDROID.md](docs/ANDROID.md).
- iOS: IPA из Releases требует подписи через Sideloadly/AltStore либо сертификатом Apple. Бесплатная личная подпись обычно требует обновления через 7 дней. [IOS.md](docs/IOS.md).
- Прошивка: батник собирает и прошивает её; отдельно загружать `.bin` после успешной работы батника не нужно. Готовый merged `.bin` записывается по адресу **0x0**. [FLASH.txt](docs/FLASH.txt).
- GitHub Actions проверяет iOS, Android, C++ обработчик команд, USB-смену пароля и отсутствие Bluetooth-разрешений в готовых пакетах. [GITHUB.md](docs/GITHUB.md).

## Структура

```text
android/                     Android: Java, Wi-Fi HTTP, Android Keystore
ios/                         SwiftUI, HTTP, Keychain
firmware/                    Wi-Fi AP + HTTP + USB-конфигурация, GPIO 2
flash_esp32.bat               Сборка и прошивка по USB

change_wifi_password.bat      Смена пароля сети через USB
change_device_token.bat       Генерация нового токена через USB
scripts/                     Инструменты и тесты
.github/workflows/           CI-сборки
```

## Для будущего робота: границы защиты

Для альбомного джойстика, SG90 и измерения 18650 см. [подключение и настройку пульта](docs/ROBOT_REMOTE.md). Для стендовых тестов через MX1508 см. [распиновку моторов A и B](docs/MOTOR_A.md).

Доступ к сети защищён WPA2-паролем, команды дополнительно требуют токен; одновременно подключается один Wi-Fi-клиент. **Это не защита от всех DoS, глушения радио или deauthentication-атак.** HTTP работает без TLS. Физический доступ к USB позволяет читать/менять настройки; NVS в этом прототипе не зашифрована.

Тесты моторов ограничены по времени. Для эксплуатации робота нужны аппаратная аварийная остановка, ограничение мощности и безопасная остановка при потере команд. Нельзя считать этот пульт готовой системой безопасности робота.

Приложение закрывает соединение при уходе в фон и не повторяет команды автоматически. После перезапуска платы/приложения подключитесь снова. Радиосвязь и USB-смену пароля проверьте на своём железе: [TESTING.md](docs/TESTING.md), [PROTOCOL.md](docs/PROTOCOL.md).
