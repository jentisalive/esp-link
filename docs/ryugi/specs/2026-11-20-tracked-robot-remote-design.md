# Альбомный пульт для гусеничного робота

Согласованный [пульт](http://localhost:27319/document/zVUYvy1THGNgs34b7ypVd): отдельные моторы для левой и правой гусениц, один экранный джойстик, SG90 для ковша с лёгкими предметами, индикация напряжения одной Li-ion 18650. Только локальный Wi-Fi, существующий токен и совместимость со стендовыми тестами.

- Android и iOS: новый альбомный экран с существующей палитрой ESP Link, джойстик слева, кнопка «Ковш» справа, напряжение и фиксированный «Стоп». Режим настройки не управляет приводом, меняет позиции, хранит их локально и умеет сбрасывать. Не перекрывать кнопки и стоп. При выходе, повороте в портрет, отпускании и уходе в фон команды прекращаются.
- ESP32: тяга только по новым кадрам текущего захвата. На остановке/тайм-ауте захват теряет силу, старые кадры не возобновляют тягу. До 300 мс без кадра, отдельная от HTTP задача. При реверсе — пауза без тяги. Стендовые тесты взаимоисключены с пультом. Остановка снимает тягу; возможен выбег.
- SG90: 50 Гц на отдельном таймере, первое нажатие выбирает исходное положение, далее переключение между откалиброванными положениями; до калибровки, на старте и при переподключении движения нет. Стоп и обрыв не посылают новую команду ковшу, начатый ход может завершиться. Не удерживает груз при снятии питания.
- Замер напряжения через делитель на свободном ADC1 до преобразователя. До включения откалиброванного измерения и при недостоверном показании — «Нет данных». Разъём не является защитой аккумулятора. Перед испытанием подтвердить аппаратную защиту, настроить 5 В и проверить линию на пиковую нагрузку.
- Тесты логики: смешивание осей, остановка/просроченные кадры, реверс, ограничения ковша и напряжения. Стенд отдельно: поднятые гусеницы, выключатель, стороны и полярность, обрыв Wi-Fi, механические пределы, сверка мультиметром. Реальную плату из этой сессии не прошивать.
- После успешных CI-сборок выпустить прошивку для uPesy ESP32 Wroom DevKit и приложения в GitHub Releases. APK с прежней подписью; IPA без подписи, если сертификат не настроен.
