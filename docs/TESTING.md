# Проверка Wi-Fi-only версии

## Автоматически

- iOS: XCTest протокола и mock HTTP, сборка IPA, проверка локального HTTP и отсутствия Bluetooth-ключей в готовом Info.plist.
- Android: unit-тесты, Android Lint, подписанный APK, проверка manifest: нет Bluetooth/геолокационных разрешений.
- ESP32: сборка `upesy_wroom`, C++ тесты LED и политики Wi-Fi пароля.
- Python: упаковка без секретов, подпись, отсутствие Bluetooth SDK в исходниках, USB handshake/ACK, запрет неправильных паролей, таймаут без повторов и отсутствие эха пароля. Serial-порт в тестах фиктивный.

```sh
python -m unittest discover -s scripts -p 'test_*.py' -v
pio test -d firmware -e native
```

## На настоящем устройстве

- [ ] Сохранить нужную старую программу и прошить именно uPesy Wroom DevKit версией 1.2.0+.
- [ ] После EN USB показывает `Wi-Fi ONLY`, `Bluetooth controller: OFF`, отдельные Device token и Wi-Fi password.
- [ ] В новом APK/IPA нет выбора Bluetooth или запросов доступа к нему; плата не рекламирует BLE. Проверять при выключенных старых платах с похожим именем.
- [ ] При обычном обновлении токен сохранился, появился новый независимый Wi-Fi пароль; после выключения/включения оба сохраняются.
- [ ] Телефон подключается к AP без интернета, приложение работает по 192.168.4.1 с токеном, включая мобильный интернет на Android.
- [ ] Неверный токен отклоняется; команды 1/on/off/status/ping работают; неизвестная команда не меняет LED.
- [ ] `change_wifi_password.bat`: неправильный/несовпадающий пароль не отправляется; выбран правильный COM-порт; ввод скрыт.
- [ ] Успешная смена: ACK, телефон отключается; старый пароль не подходит, новый подходит; токен прежний.
- [ ] После EN и отключения питания новый пароль сохранился. USB-смена работает даже при занятом/недоступном Wi-Fi.
- [ ] Ошибочный порт/старая прошивка не получают пароль до правильного handshake.
- [ ] При потерянном ACK нет автоматической повторной отправки; состояние проверяется вручную по USB.
- [ ] Уход приложения в фон и потеря питания платы закрывают сеанс, после возврата нужно подключиться заново.
- [ ] В репозитории нет приватных ключей, а в журналах приложения — токена и Wi-Fi пароля.

CI не проверяет реальные радиосигналы, питание, USB-драйвер или физический светодиод. Проверка отсутствия advertising/подключений и смены пароля на своей плате обязательна. DoS/глушение Wi-Fi не считаются устранёнными.
