# Android — Wi-Fi ONLY, 1.2.5

Установите `ESPLink-android-v1.2.5.apk` из Releases на Android 8+. APK подписан прежним ключом и устанавливается поверх 1.2.4. Если телефон просит — разрешите установку из выбранного источника. Sideloadly и Apple ID не нужны. Кнопки мотора 1 требуют прошивку 1.2.5 или новее.

**Перепрошейте ESP32 версией 1.2.0+, чтобы выключить Bluetooth на самой плате.** Старые релизы содержат Bluetooth; новая версия приложения сама старую прошивку не меняет.

## Подключение

1. `get_token.bat` + EN на плате: получите **Device token** и отдельный **Wi-Fi password**.
2. В настройках Android подключитесь к ESP32-Link-XXXX с Wi-Fi password. Останьтесь в сети без интернета.
3. Вернитесь в ESP Link, укажите `192.168.4.1` и Device token, нажмите подключение.
4. Отправьте `1` или нажмите «Мигнуть 3 раза». Также: on, off, status, ping.

Приложение не содержит Bluetooth SDK-кода, поиска устройств, Bluetooth-разрешений или разрешений геолокации. HTTP-запросы направляются через подключённую Wi-Fi-сеть, не через мобильный интернет. Принимаются частные IPv4-адреса и имена `.local`; в базовой прошивке используйте IP, mDNS не реализован. Перенаправления HTTP запрещены.

## Смена пароля

На компьютере запустите `change_wifi_password.bat` в папке проекта. Ввод скрыт; пароль не передаётся как аргумент процесса и не сохраняется батником в файлы. На плате он сохраняется в NVS. После успеха забудьте старую Wi-Fi-сеть на телефоне и подключитесь с новым паролем. Токен приложения не меняется. Батник требует Wi-Fi-only прошивку 1.2.0+ и `.venv` с PlatformIO/pyserial.

## Разработка

Java / Android SDK, minSdk 26, compile/target SDK 35, JDK 17, Gradle 8.11.1:

```sh
cd android
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

На Windows используйте `gradlew.bat`. CI проверяет тесты, Lint, release-подпись, фактический manifest APK и отсутствие Bluetooth/геолокационных разрешений.

Release-ключ: GitHub Secrets `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, alias `esplink`. Приватная резервная копия — `.signing/`, не публикуйте её. Для обновления поверх установленной версии нужен тот же ключ. PR-сборки не получают ключ; подписанная сборка выполняется только в main.

Последний токен сохраняется зашифрованным AES-GCM с ключом Android Keystore. При удалении приложения токен вводится заново. При уходе в фон сеанс закрывается. Автопереподключения и повторов команд нет. Радиосвязь на настоящем телефоне не заменяется тестами CI.
