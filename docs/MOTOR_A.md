# Тест мотора 1 (MX1508)

Нужны приложение и прошивка ESP Link 1.2.5 или новее.

| Драйвер | Подключение |
| --- | --- |
| MOTOR-A / OUT1–OUT2 | Только мотор 1 |
| INT1 | ESP32 GPIO 25 |
| INT2 | ESP32 GPIO 26 |
| `+` | Отдельное питание, подходящее по напряжению и току драйверу и мотору |
| `−` | Минус питания мотора и общий GND ESP32 |

Не питайте мотор от контакта 3.3 V ESP32. Для этой проверки оставьте MOTOR-B неподключённым; INT3/INT4 и GPIO 27/14 прошивка не настраивает. Для надёжного выключения при сбросе ESP32 проверьте, что на INT1/INT2 есть подтяжка к GND (например, по 10 кОм, если её нет на модуле).

В приложении по Wi-Fi нажмите **«Тест мотора 1»** (`m1test`). Мотору задаётся ШИМ 150/255 вперёд на 2 с, затем 1 с оба входа LOW, затем 255/255 назад на 2 с и окончательная остановка (оба входа LOW). Повтора и движения при включении нет. Если реальное направление противоположно ожидаемому, поменяйте местами провода мотора при выключенном питании.

**«Стоп мотора 1»** (`m1stop`) запрашивает остановку по сети. Плата также запрашивает остановку при обнаружении отключения клиента от точки доступа. Если связь пропала без немедленного обнаружения, цикл всё равно ограничен по времени отдельной задачей. Отключение приложения само по себе не равно отключению телефона от Wi-Fi.

Это стендовый тест, не аварийная система. Перед тестом вывесьте колёса, уберите руки и держите под рукой физический выключатель питания двигателя. Команда «Стоп» по Wi-Fi не заменяет физический выключатель. Ответ платы подтверждает приём команды, а не движение или остановку вала.
